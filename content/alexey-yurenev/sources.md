# Alexey Yurenev — source record

## Selection and rights note

This eleven-image working set is drawn from *Silent Hero* (2019–ongoing), the
artist's investigation of World War II memory through family photographs,
archives, interviews, field work, and machine learning. The sequence is the
strongest available basis for this chapter because it makes its subject visible
as a compositional problem: documentary landscape, damaged archival evidence,
synthetic reconstruction, and image datasets all share the frame.

All files were downloaded directly from the public image service embedded in
[Yurenev's official *Silent Hero* project page](https://www.yurenev.com/projects/silent-hero).
That page identifies the project, its 2019–ongoing date, and the credit
`© YURENEV, Silent Hero, 2019 – ongoing`; it describes the artist's combination
of machine learning, family photographs, archives, veteran interviews, and
forensic fieldwork. The page publicly displays the works but grants no open
licence, so every use below is **fair-use**, not open access. Creator and
rightsholder notice: Alexey Yurenev / `© YURENEV`.

For every entry, factor 1 favors this nonprofit-critical use: the book uses a
web-sized copy for criticism, scholarship, and transformative composition
teaching. Factor 2 weighs against use because the works are creative,
contemporary photographs and synthetic-image constructions. Factor 3 favors
the use only to the extent that each complete displayed frame is necessary to
study its spatial argument; no decorative crop is used. Factor 4 favors the
limited use: each copy is credited and linked to the artist's page and does not
replace an artwork, the artist's book, an exhibition, or a licensed
reproduction.

Each file opened successfully after download. Long edges range from 1,366px to
8,192px, above the 640px acquisition floor; none was upscaled or altered.
