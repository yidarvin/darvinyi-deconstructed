# Penelope Umbrico — source shortlist

## Selection and rights basis

This twelve-image set follows the compositional argument in the registry: Umbrico
turns individually ordinary web photographs, camera-app processing, and obsolete
screens into collective image fields. The sources are public display renditions
served by [David B. Smith Gallery's Umbrico works index](https://www.davidbsmithgallery.com/artists/penelope-umbrico/).
The gallery identifies the artist and each work but supplies no open licence. The
set is therefore **fair-use** throughout, not open content. [SFMOMA's
installation article](https://www.sfmoma.org/read/sunsets-umbrico/) identifies
the foundational *Suns* work as © Penelope Umbrico. Where the gallery record
does not state a fuller notice, the entries retain that known author notice and
credit Penelope Umbrico with the source gallery.

Each individual assessment below applies the four factors: **(1)** this is a
nonprofit, transformative use for criticism, scholarship, and composition
teaching; **(2)** the underlying artwork is creative, weighing against use;
**(3)** the complete displayed frame is needed to analyze its grid, sequencing,
or mediated surface rather than merely decorate the chapter; and **(4)** the
credited, source-linked, web-sized copy does not replace the artwork, its
gallery record, or a licensed reproduction.

The original public responses were opened after download. PNG display responses
were format-normalized to JPEG only because this pipeline's raw-input convention
is `NN-title.jpg`; no image was cropped, upscaled, retouched, or otherwise
altered. Eleven files have long edges of
1,224–1,920px. Item 08 is a 600px-long-edge public rendition: an allowed
480–639px exception because the full vertical split-screen, color field, and
central mountain remain unambiguously legible.

## Source investigation note

The pass checked the artist's project index, SFMOMA's artist/collection material
for the foundational *Suns* installation, and the public gallery catalogue. The
artist site itself was reachable through search indexing but did not present a
usable direct response from this environment; this is not treated as a source
failure because the gallery catalogue publicly served twelve verified display
files. The acquired set exceeds the registry minimum of four without an access
roadblock, so no limited-source fallback is used.
