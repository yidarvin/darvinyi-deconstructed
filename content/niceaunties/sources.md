# Niceaunties — source shortlist

Niceaunties is the Singapore-based artist Wenhui Lim's AI-led *Auntieverse*: a
world in which older Asian women occupy speculative cities, domestic spaces, and
runways as agents rather than background types. This 12-image group samples the
project's social portraiture, civic scale, beauty satire, and fashion tableaux.
The artist's public site is the authoritative display source for all of the works;
the site identifies the *Auntiesocial* chapter as 2023 and describes *Auntie City*,
*Spa Menu*, and the fashion chapter in the artist's own terms. Every acquired file
is a public 1,500px display rendition, downloaded directly without login, bypass,
or alteration (apart from a format-preserving WebP-to-JPEG transcode for file 01).
