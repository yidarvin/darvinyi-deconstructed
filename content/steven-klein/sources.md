# Steven Klein — source record

## Selection and rights note

This ten-image research set samples Steven Klein's cinematic editorial vocabulary
across 2004–14: constructed domestic scenes, celebrity portraiture, aggressive
color, and figures made to read as characters within a larger set. All ten files
were retrieved as public, unaltered Vogue web renditions from [Vogue's interview
with Klein about these images](https://www.vogue.com/article/steven-klein-vogue-book-interview).
The article captions each work and credits its photographs to Steven Klein. No open
licence is offered, so every use below is **fair-use**, not open content. Each file
opened successfully after acquisition and is 1,600px or longer on its long edge
(the first is 2,560px); none was upscaled or retouched.

Each assessment is specific to the cited work. Factor 1 favors this chapter's
transformative criticism, scholarship, and composition teaching rather than
decoration; factor 2 weighs against use because each is a highly creative fashion
photograph; factor 3 supports retaining the complete frame because the teaching
depends on the relationships across it; factor 4 favors this limited web-sized,
credited, linked reference copy, which does not substitute for the Vogue article,
an original work, or a licensed reproduction.
