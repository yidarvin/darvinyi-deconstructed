# Candida Höfer — source shortlist

This ten-work set concentrates on Höfer's unpeopled public interiors—libraries,
museums, and architecturally emphatic rooms—where centered viewpoint, repeated
shelving, visible thresholds, and color make institutions read as portraits. Nine
copies are public, web-sized JPEG display renditions served by ALBERTINA's
collection records (their longest edge is 750px). The final copy is Museo Reina
Sofía's directly served 1520 × 1509px collection display image. Each file was
downloaded without a login, opened locally, and preserves the complete published
frame.

**Rights basis:** **fair-use** for every selection. These are copyrighted
photographs, not open-licensed files. ALBERTINA identifies its nine records as
`© Bildrecht, Wien 2026` and credits `ALBERTINA, Wien – The ESSL Collection`;
the Reina Sofía record identifies Candida Höfer as the artist (its supplied work
image bears the museum's collection identifier AD03433). Each assessment below
applies all four factors: this book's use is transformative criticism,
scholarship, and composition teaching; the underlying photographs are highly
creative; the intact web frame is necessary to analyze spatial organization; and
the credited, record-linked display copy is web-sized and does not replace the
original, museum record, or a licensed reproduction.

## Research context

Museo Reina Sofía's artist collection page lists 33 Höfer works, including the
theater, library, university, waiting-room, and museum subjects represented in
this chapter: https://www.museoreinasofia.es/colecciones/artista/hofer-candida.
The Hessisches Landesmuseum Darmstadt describes Höfer's best-known large-format
works as empty public interiors—museums, opera houses, theaters, churches, zoos,
and libraries—and characterizes them as portraits of spaces rather than merely
architectural photographs: https://www.hlmd.de/en/discover/special-exhibitions/2025/candida-hoefer-fotografien.
