# Danielle Ezzo — source record

## Selection and acquisition note

This is a ten-image, camera-made selection from Danielle Ezzo and Marin Sardy’s
*Psychic Telephone* (2024–). Ezzo’s public project page explains that Sardy’s
interviews with people about psychic experiences are distilled into texts; Ezzo
uses deliberately low-resolution text-to-image output as a prompt, then makes
the final photographs with a camera. The selection keeps the series’ key visual
problem in view: a speculative machine image is translated into still-life,
light, surface, and spatial decisions that can be read in a complete frame.

All files were downloaded directly from Ezzo’s public artist portfolio without
a login, paywall, or access-control bypass. The artist’s page displays no open
licence. Copyright/rightsholder notice for every image: **© Danielle Ezzo**
(artist and portfolio publisher); *Psychic Telephone* is credited on the page
as a collaboration with author Marin Sardy. Each JPEG below opens successfully
and exceeds the 640px long-edge floor (the shortest is 1,766px); no file has
been upscaled or altered.

Every item below is an individual **fair-use** assessment for this nonprofit
book’s criticism, scholarship, and transformative composition teaching. The
works are creative, published contemporary photographs, which weighs against
use. However, the complete frame is necessary to teach the particular relation
of light, objects, edges, and void named below; a crop would defeat the analysis.
Only a web-sized reference copy is used. Each item is credited and linked to
Ezzo’s public project record and cannot substitute for the original work, an
exhibition, a print, or a licensed reproduction. Those four factors are applied
to each image below, rather than presumed from the educational setting.

**Project/source record:** [Danielle Ezzo, *Psychic Telephone*](https://www.danielleezzo.com/art/psychic-telephone).
