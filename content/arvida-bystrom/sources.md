# Arvida Byström — source shortlist

This source pass foregrounds complete-frame, publicly displayed records from
Fotografiska's *Inflated Fiction* press release, the artist's representing gallery,
and the 2018 *Virtual Normality* exhibition context. No public-domain or
open-licence rendition was identified. The ten files below are therefore narrowly
documented **fair-use** copies for criticism, scholarship, and transformative
composition teaching. All were retrieved as public web display JPEGs and opened
successfully; the long edges run from 640px to 7,874px. The 640px *Self Portrait*
is retained because its face, body, and clipped domestic setting remain legible and
it anchors the chapter's early networked-self image.
