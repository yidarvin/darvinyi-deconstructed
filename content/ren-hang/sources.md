# Ren Hang — image sources

All selected files were acquired from the public artwork images served by [Blindspot Gallery's Estate of Ren Hang page](https://blindspotgallery.com/artist/ren-hang/). Blindspot Gallery represents the Estate of Ren Hang; its public artwork API supplies the title, year, and display-file dimensions recorded below. The gallery describes the work as carefully choreographed arrangements of bodies, colour, animals, and plants. The Alexander Tutsek Foundation independently credits the same source route as “© Ren Hang, courtesy Estate of Ren Hang and Blindspot Gallery.”

Every selection below is a public web display image, but no open licence is stated. The use basis is therefore **fair-use**, assessed separately for each work. Each copy is a complete, web-sized display file used for nonprofit criticism, scholarship, and transformative composition teaching; the entire frame is necessary to discuss its spatial construction; it is credited and linked to the authoritative gallery record; and it neither replaces the original nor a licensed print/reproduction. Copyright/credit: © Estate of Ren Hang; courtesy Blindspot Gallery.
