# James Coupe — source shortlist

This eleven-image set follows Coupe's machine-vision practice from the emptying surveillance panorama through demographic profiling, platform labor, and the *Warriors* deepfake installations. The artist's own public portfolio provides the work records and the publicly visible display files used here. The site currently has a faulty HTTPS certificate, so the accessible public HTTP records and their direct image responses were used; no login, paywall, access-control bypass, or alteration was involved. Every downloaded file opened successfully. All are copyrighted contemporary works or installation/documentation photographs, so none is treated as open-licensed.

**Rights basis:** **fair-use** for every selection. These separate assessments use a complete, credited, web-sized public display image for nonprofit criticism, scholarship, and transformative composition teaching. Each whole frame is needed to analyze its framing, screen arrangement, bodies, or algorithmic image operation; a crop would defeat that purpose. The book links to the artist's work record, credits the artist and any identified documentation photographer, and the web copy does not replace the installation, original documentation, museum record, or a licensed reproduction.

## Research context

- The artist's [biography](http://jamescoupe.com/?page_id=371) identifies Coupe's practice as real-time public surveillance systems, interactive deepfake installations, and work with Mechanical Turk laborers.
- ICP's [2020 *Warriors* release](https://www.icp.org/sites/default/files/ICP%20Press%20Release%20-%20James%20Coupe%20Warriors%20-%201-13-20_1.pdf) independently documents the installation's use of deepfakes, Face++, ImageNet, and scenes from Walter Hill's 1979 film.
- The Henry Art Gallery's [*Sanctum* record](https://henryart.org/exhibitions/sanctum) confirms its 2013–15 façade installation and explains its use of profiling and social-media material.
