# Phillip Toledano — image sources

## Source route and rights assessment

This selection is drawn from the publicly viewable 16-image [LensCulture project page for *Another America*](https://www.lensculture.com/projects/1827635-another-america). LensCulture identifies the project as **Another America**, names **Phillip Toledano** in the image copyright metadata, and serves the complete display JPEGs without a login or technical access control. The publisher’s [book record](https://www.simonandschuster.com/books/Another-America/Phillip-Toledano/9791280978127) dates the book to 2024 and describes the series as AI-generated alternate histories set in the 1940s and 1950s. No open licence was found, so every selection below is used on a **fair-use** basis. Credit/copyright notice: © Phillip Toledano; project text credits words to John Kenney where present.

For each individual image: (1) this nonprofit book uses it for criticism, scholarship, and transformative composition teaching, rather than decorative republication; (2) the work is a published creative image, which weighs against use but is necessary to analyse; (3) the complete, web-sized frame is the minimum amount needed to examine its visual construction; and (4) the chapter credits and links to the public project page and does not replace the artist’s work, book, or licensed reproduction. Each entry additionally identifies the frame-specific teaching need.

## Acquisition notes

- All twelve selected files are direct public JPEG responses from LensCulture, not screenshots. Each opens successfully and measures 1000–2000 px on its long edge, exceeding the normal 640 px quality floor.
- The source page supplies several additional project images. Twelve were retained because together they give a focused progression through Toledano’s AI-made, mid-century alternate-history visual grammar: centered portrait, urban grid, surreal intrusion, scale reversal, and tonal simulation.
- No public-domain or openly licensed rendition was identified. The project page and the image response metadata credit Phillip Toledano, so no image is represented as open.
