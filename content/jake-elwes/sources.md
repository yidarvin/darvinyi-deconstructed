# Jake Elwes — source record

## Selection and acquisition note

This twelve-image set follows the visible trail through Elwes's machine-vision
practice: the synthetic birds of *CUSP* (2019), the altered faces and display
formats of *Zizi — Queering the Dataset* (2019–ongoing), and the deepfake-drag
performance system of *The Zizi Show* (2020–23).  The artist's public project
pages identify the works, dates, collaborators, and display contexts, and
serve the same JPEGs directly to ordinary web visitors.  The V&A presentation
page additionally supplies its displayed photo credit.

None of these public display files carries an open licence, so every item is
used as **fair-use**, never as an open download.  The creator is Jake Elwes;
where stated, the credit is preserved exactly (including © Victoria and Albert
Museum, London, and the named installation photographer).  The four-factor
assessment is applied to each entry below: (1) this is criticism, scholarship,
and transformative composition teaching; (2) each source image records a
creative contemporary artwork or performance and that factor weighs against
use; (3) the complete displayed frame is needed to teach the stated spatial,
temporal, or dataset relation; and (4) only a web-sized, credited copy is
kept, linked to the artist's public record, and it does not replace the work,
an exhibition visit, a museum record, or a licensed reproduction.  Files were
downloaded without alteration and opened successfully; their long edges range
from 986px to 3,500px, all above the 640px floor.
